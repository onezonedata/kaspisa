# kaspisa

Бесплатный сервис для продавцов Kaspi, который ставится на свой компьютер или сервер. Бот опрашивает карточки товаров, сравнивает цену магазина с конкурентами и меняет её по выбранной стратегии, не выходя за минимальную и максимальную цену.

## Условия

Программа работает без гарантий, вы пользуетесь ею на свой риск; подробности — в [TERMS.md](TERMS.md) (черновик). Лицензия — AGPL-3.0, см. [LICENSE](LICENSE).

## Установка и эксплуатация

- Установка: [docs/install.md](docs/install.md).
- Эксплуатация, резервные копии, обновление: [docs/deploy.md](docs/deploy.md).

Запись цен по умолчанию выключена: бот только наблюдает, пока вы сами не включите запись.
