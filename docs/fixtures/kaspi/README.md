# Примеры ответов Kaspi

Используются в тестах вместо сети. Секретов здесь нет и быть не должно.

Данные магазина, товаров и продавцов заменены вымышленными; форма ответов сохранена.

- `edit-price.json` — полный ответ чтения товара.
- `price-update-request.json`, `price-update-response.json` — тело и ответ записи цены.
- `offers.json` — ответ со списком продавцов карточки. **Сокращён:** семь продавцов с основными полями.
- `offer-full-sample.json` — два продавца из того же ответа со всеми полями (снято позже, цены отличаются от `offers.json`).
- `product-list.json` — ответ списка товаров кабинета, два товара; `allCityPrices` сокращён до двух городов, списки картинок — до трёх.
- `login-flow.json` — два запроса входа с кодом из письма; все значения заменены на `***`.
- `session-merchants.json` — ответ `GET /s/m`.
- `null-stock-product.json` — товар с неуказанным остатком: строка списка (сокращена), чтение и запись, отправленная кабинетом.
- `point-off-product.json` — товар с выключенной точкой: строка списка (сокращена) и чтение.
- `stock-counted-product.json` — товар с указанным остатком: строка списка PP1 — 100, чтение PP1 — 94 (ADR 0036). **Собрано по наблюдению, не полный снятый ответ:** значения заменены, порядок точек в чтении и тело записи не сохранены.
- `offers-server-2026-11-15.json` — ответ `POST /yml/offer-view/offers/{masterSku}`, снятый запросом с сервера (не из браузера): четыре продавца, цены `2998.0`, `2998.0`, `2999.0`, `4990.0` (float с `.0`; в браузере JavaScript превращает их в `2998`, как в `offers.json`). Секретов нет. Значения продавцов и товара заменены, форма и цены не тронуты.
