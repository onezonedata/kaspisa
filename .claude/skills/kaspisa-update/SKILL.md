# Обновление kaspisa

Правила А1–А13 — в `AGENTS.md` корня репозитория. Скрипт `update.sh` сам откатывает изменения при сбое до сообщения «Готово»; агент только запускает его и читает журнал.

## Перед началом

1. Проверь `id -u`. Если результат 0, остановись (А9).
2. Проверь `git status`: рабочее дерево должно быть пустым. Если нет, остановись и покажи владельцу список файлов (`git status --short`).
3. Узнай у владельца метку (`vX.Y.Z`) или ветку. Не меняй `KASPISA_IMAGE_PREFIX` в `.env` (А2).
4. В режиме сборки нужны `uv` и Node.js с npm (`docs/deploy.md`, раздел «Что понадобится»); `update.sh` сам проверяет их до слияния. Флаг `--full-tests` (полный `make test`, нужен Google Chrome) добавляй, только если владелец сам правил код и просит полную проверку. Если чего-то нет, остановись.

## Запуск

5. Владелец подтверждает запуск. В неинтерактивном режиме (`claude -p`) запрос подтверждения отклоняется: не повторяй команду и не ищи обход, передай владельцу команду `bash update.sh <метка или ветка>`; он запускает её сам, а ты потом читаешь журнал. В интерактивной сессии после подтверждения запусти в tmux на сервере одним сеансом и дождись его конца; не опрашивай процесс или журнал по SSH циклом (каждый вход даёт сообщение владельцу, `docs/install.md`):

   ```
   bash update.sh <метка или ветка>
   ```

   Журнал — `backups/update-<метка времени>.log` (права 600). Последний журнал: `ls -t backups/update-*.log | head -1`, затем `tail -n 50` этого файла. Скрипт игнорирует обрыв SSH; запускать его рекомендуется в tmux.

6. Не запускай обновление повторно, пока предыдущий процесс работает.

## Код выхода

- `0` — готово. В журнале строка «Готово: работает версия …». Сообщи версию владельцу.
- `1` — обновление не удалось, откат выполнен, работает прежняя версия. Покажи владельцу строки журнала с причиной.
- `2` — откат не удался или `.env` не записан. Отдай владельцу раздел «Ручные шаги после сбоя» в `docs/deploy.md`, раздел 6. Ручные шаги агент сам не выполняет.

После сообщения «Готово» автоматического отката нет: новый worker мог записать цены.
