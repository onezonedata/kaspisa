# Условия использования kaspisa

## 1. Лицензия и правообладатель

kaspisa распространяется по лицензии GNU Affero General Public License версии 3 (AGPL-3.0). Полный текст лицензии — в файле `LICENSE`. Правообладатель: onezonedata, Copyright (C) 2026 onezonedata. Этот раздел — пересказ. При расхождении с текстом лицензии силу имеет текст лицензии.

## 2. Программа предоставляется «как есть»

kaspisa предоставляется «как есть», без гарантий работоспособности, пригодности для конкретной цели, отсутствия ошибок и получения прибыли. Отказ от гарантий и ограничение ответственности — разделы 15 и 16 AGPL-3.0.

## 3. Доработки и снятие проверок

Владелец отвечает за изменения кода, которые сделал сам или его агент. Особо: снятие или ослабление проверки минимальной и максимальной цены, включение записи цен в Kaspi (`KASPISA_DRY_RUN=false`, режим `live`). Убытки от цены вне заданных границ после таких изменений несёт владелец.

## 4. Договор с Kaspi

kaspisa работает через сессию кабинета продавца Kaspi. Соответствие договору с Kaspi и правилам кабинета проверяет владелец: автор этого не изучал и не гарантирует. Ограничения, блокировки и изменения со стороны Kaspi — риск владельца.

## 5. Доступы

Пароли кабинетов Kaspi, ключ шифрования, файл `.env` и копии базы хранятся только у владельца. Автор их не получает. Потеря ключа шифрования делает зашифрованные доступы продавцов нерасшифровываемыми. Утечка с сервера или через агента, которому владелец дал доступ, — ответственность владельца.

## 6. Данные

kaspisa не передаёт данные магазинов автору. Проверка новой версии, если она включена (`KASPISA_UPDATE_REPO`), обращается к GitHub Releases, и GitHub видит адрес сервера. Уведомление о входе по SSH, если владелец его настроил, отправляет текст сообщения в Telegram.

## 7. Исходный код по сети

Если владелец изменил код и даёт пользоваться установкой по сети другим людям, он обязан предложить им исходный код изменённой версии (раздел 13 AGPL-3.0). Ссылка на исходный код в интерфейсе пока не добавлена.

## 8. Поддержка

Поддержка — по возможности, через Issues репозитория `onezonedata/kaspisa`. Сроков ответа и обязательств нет.
